# Policy Change Brief

Compare two supplied versions of an internal policy and summarize operational changes.

Copy the instructions in [SKILL.md](SKILL.md) into ChatGPT or Claude and supply the material you want reviewed. In an Agent Skills environment, install the folder with its original name.

## Example

A revision changes expense submission from within ten days to within five working days.

Expected behavior: Preserve both the new interval and its working-day qualifier.
